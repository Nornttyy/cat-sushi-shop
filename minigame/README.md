# 海边寿司店 · 微信小游戏

这是网页版本迁移到微信小游戏的原生 Canvas 工程。它不是网页套壳：界面、触控、存档和广告都使用微信小游戏 API。

当前可玩内容：

- 横屏主菜单与制作台；
- 点击米饭和玉子烧，再点击菜板制作玉子烧寿司；
- 点击顾客出餐并保存贝壳；
- 已预留微信原生激励视频广告接口，只有广告完整播放成功才会发放奖励。

## 在微信开发者工具中打开

1. 打开微信开发者工具，选择 **导入项目**。
2. 选择此目录 `minigame`。
3. 开发阶段可使用 `touristappid`；正式发布前，在 `project.config.json` 换成你自己的微信小游戏 AppID。
4. 在 `src/config.js` 填入微信小游戏后台生成的激励视频广告位 `adUnitId`。

广告位留空时，游戏不会假装播放广告，也不会发奖励。先在微信小游戏后台创建广告位并完成相关资质/开通流程，再填入真实 ID。

下一阶段会把网页中的完整订单、商店、钓鱼和排行榜逐项迁入这个工程。
